Proyek Smart Urban Green Logistics & Carbon-Cost Optimization adalah sebuah dashboard analitik berbasis web yang dirancang untuk memantau, menganalisis, dan mengoptimalkan efisiensi biaya operasional serta jejak emisi karbon (carbon footprint) pada armada pengiriman perkotaan. Tujuan utama dari proyek ini adalah memberikan visibilitas data secara real-time mengenai korelasi antara jarak tempuh, jenis bahan bakar, berat muatan, serta kondisi lalu lintas terhadap total emisi dan biaya operasional.   Permasalahan utama yang diselesaikan adalah tingginya emisi gas rumah kaca dan inefisiensi biaya logistik akibat pemilihan rute serta bahan bakar yang kurang optimal. Target pengguna dari sistem ini adalah manajer logistik, operator armada, serta pengambil keputusan di perusahaan pengiriman yang ingin beralih ke praktik operasional ramah lingkungan (green logistics). Fungsi utama yang dikembangkan di dalam sistem ini meliputi filter data interaktif, visualisasi metrik utama, analisis komparatif emisi per rute, serta integrasi model Machine Learning (Random Forest) untuk memprediksi emisi karbon berdasarkan parameter pengiriman baru.
